# Spice Garden – Restaurant Website

Project Type:Responsive Restaurant Website

Technologies: HTML5, CSS3, JavaScript

Description:

Spice Garden is a responsive restaurant website designed to showcase restaurant information, food menus, pricing and contact details.

Features:
- Responsive navigation bar
- Restaurant introduction section
- Food menu with images and prices
- Contact information
- Interactive JavaScript functionality
- Mobile-friendly layout

Purpose:

This project demonstrates my frontend web development skills and my ability to create simple, user-friendly business websites.
